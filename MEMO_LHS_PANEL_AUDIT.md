## Methodology (find → adversarially verify → synthesize)
Three sequential Workflows with a manager gate between each (manager stays lean — workflows return digests, raw data lands in files).

- **Phase A — FIND** (Workflow, 24 finders = 8 subjects × 3 cluster-groups). Deep code analysis primary; cells unresolved by code-read marked UNVERIFIED, never PASS. Each finder reads `docs/memos/lhs-panel-audit/_finder-brief.md`, writes `raw/<subject>-<group>.json`, returns a lean digest.
- **Manager gate 1** — dedupe cross-subject findings (assembler agent), assemble draft MATRIX, reject applicable-but-UNVERIFIED cells.
- **Phase B — VERIFY** (Workflow, 2 adversarial skeptics per deduped finding, each prompted to REFUTE; adjudicator on split). Confirms/refutes + nails deepest root cause + blast radius. Writes `verdicts/<id>.json`.
- **Manager gate 2** — flip matrix cells to final state; promote CONFIRMED findings to the ranked bug list.
- **Phase C — SYNTHESIZE** — ranked bug list + defect-class roll-up + coverage proof. Finalize this memo.
